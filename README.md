# Sakadea Jagath — Portfolio

A static personal portfolio focused on penetration testing, security experience, vulnerability research, and responsible disclosure. Earlier development roles and projects are preserved in an optional expandable section.

## Preview

Open `index.html` in a browser. No build step or dependency installation is required.

For a local HTTP preview, run from this folder:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:4173`.

## Files

- `index.html`: profile, experience, education, projects, credentials, and contact details.
- `css/style.css`: responsive layout, colors, and reduced-motion support.
- `js/main.js`: mobile navigation, active navigation, screenshot dialog, and footer year.
- `assets/`: original project images, portrait, downloadable CV, and credential documents.
- `assets/certificates/`: lightweight previews rendered from the original credentials.
